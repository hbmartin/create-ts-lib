# Security Policy

## Supported Versions

The latest release and the default branch are supported for security fixes.

## Reporting a Vulnerability

Please report suspected vulnerabilities through GitHub's private vulnerability reporting:

https://github.com/hbmartin/create-ts-lib/security/advisories/new

Include the affected version, steps to reproduce, impact, and any known workaround. Please do not open a public issue for suspected vulnerabilities until a fix or mitigation is available.
